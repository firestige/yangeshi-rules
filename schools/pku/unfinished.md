# 需人工核对与执行限制

- `PKU-STRUCT-01` 主要部分及排列
- `PKU-STRUCT-02` 各部分另起一页
- `PKU-COVER-04` 院系、专业与导师资料
- `PKU-COVER-07` 可选英文内封与中文封面
- `PKU-DECL-01` 版权声明统一格式
- `PKU-ABS-03` 中文摘要篇幅建议
- `PKU-KEY-02` 关键词独立行与页下方
- `PKU-ABS-05` 受资助摘要页脚
- `PKU-ABS-06` 英文摘要项目与顺序
- `PKU-ABS-10` 英文标点及译文一致
- `PKU-TOC-01` 目录条目组成与级数
- `PKU-LIST-01` 可选图表目录
- `PKU-SYMBOL-01` 主要符号对照表的条件与位置
- `PKU-BODY-03` 引言与结论结构
- `PKU-FIG-04` 可选英文图名
- `PKU-TABLE-05` 可选英文表名与量单位
- `PKU-OBJ-02` 图表附注及图表题间距
- `PKU-REF-03` 全文引用制度一致
- `PKU-REF-08` 著者出版年文种及作者排序
- `PKU-REF-09` 参考文献著录标点
- `PKU-REF-10` 不同文献类型的著录项目
- `PKU-REF-11` 引文细节及重复引用
- `PKU-REF-12` 责任者、书刊名及数字著录
- `PKU-REF-13` 允许变通和省略的项目
- `PKU-REF-14` 电子文献及学位论文类型标志
- `PKU-APP-03` 附录参考文献独立编号
- `PKU-DECL-02` 原创性声明、授权及签字
- `PKU-RESULT-01` 可选简历与成果列表
- `PKU-CONTENT-01` 语言、术语和单位
- `PKU-CONTENT-02` 题目摘要和研究叙述
- `PKU-PRINT-01` 纸质打印装订和电子交付
- `PKU-TEMPLATE-01` 硕士模板说明及示例残留
- `PKU-TEMPLATE-02` 示例文献真实性边界
